# 战锤40K 图片轮播

这是一个自动轮播战锤40K主题图片的网页应用。

## 功能特性

- ✨ **自动轮播**：每3秒自动切换到下一张图片
- 🎲 **随机播放**：图片顺序随机洗牌
- 🔄 **循环播放**：100张图片播放完毕后自动从头开始，并重新随机排序
- 🖼️ **动态获取**：自动从网上获取相关主题图片
- ⌨️ **键盘控制**：支持空格键或右箭头键手动切换
- 📱 **响应式设计**：适配不同屏幕尺寸

## 使用方法

### 本地运行

1. 直接在浏览器中打开 `index.html` 文件
2. 轮播将自动开始，显示100张战锤40K相关主题的图片
3. 使用空格键或右箭头键可以手动切换图片

### 技术实现

- **图片来源**：
  - Unsplash API（提供高质量免费图片）
  - Picsum Photos（随机图片服务）
  - 相关主题关键词：space marine, warhammer, sci-fi warrior, futuristic armor 等

- **随机算法**：使用 Fisher-Yates 洗牌算法确保真正的随机性

- **轮播逻辑**：
  - 预加载前10张图片以确保流畅播放
  - 使用CSS过渡效果实现平滑切换
  - 每3秒自动切换一次
  - 100张图片循环后重新洗牌

## 自定义配置

### 修改轮播速度

在 `index.html` 中找到以下代码并修改时间（单位：毫秒）：

```javascript
carouselInterval = setInterval(showNextSlide, 3000); // 3000 = 3秒
```

### 修改图片数量

在 `generateImageUrls()` 函数中修改循环次数：

```javascript
for (let i = 0; i < 100; i++) { // 修改100为其他数字
```

### 使用自己的图片

如果你想使用自己的战锤40K图片，可以直接替换 `imageUrls` 数组：

```javascript
const imageUrls = [
    'your-image-url-1.jpg',
    'your-image-url-2.jpg',
    // ... 更多图片URL
];
```

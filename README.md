# 战锤40K 图片轮播

这是一个自动轮播战锤40K主题图片的网页应用。

## 功能特性

- 🖼️ **手动浏览模式**：完全手动控制，按需加载图片
- 🎲 **随机播放**：图片顺序随机洗牌
- 🔄 **循环播放**：100张图片浏览完毕后自动从头开始，并重新随机排序
- 🔒 **可靠加载**：确保每张图片成功加载后才显示
- ⚡ **智能重试**：图片加载失败自动重试（最多3次）
- ⏱️ **超时保护**：10秒超时机制，避免无限等待
- 💾 **智能缓存**：
  - 预加载前5张图片
  - 当前图片加载后，自动预加载前后相邻图片
  - 已加载图片缓存在内存，切换瞬间完成
- ✓ **加载状态显示**：实时显示每张图片的加载状态
- ⌨️ **键盘控制**：
  - 空格/右箭头：下一张
  - 左箭头：上一张
- 🖱️ **按钮控制**：左右导航按钮，点击切换
- 📱 **响应式设计**：适配不同屏幕尺寸
- 🚀 **性能优化**：使用800x600尺寸图片，加载更快

## 使用方法

### 本地运行

1. 直接在浏览器中打开 `index.html` 文件
2. 等待初始图片加载（预加载前5张）
3. 加载完成后自动显示第一张图片
4. 使用键盘或按钮手动切换图片

### 操作控制

- **键盘控制**：
  - `空格键` 或 `→`（右箭头）：下一张
  - `←`（左箭头）：上一张
- **鼠标控制**：
  - 点击左右导航按钮切换图片

### 图片加载机制

- 每次切换图片时，如果图片未加载会显示"正在加载..."提示
- 图片加载失败会自动重试最多3次
- 超过10秒未加载成功会使用占位符图片
- 成功加载的图片会显示"✓ 已加载"状态
- 自动预加载下一张和上一张图片，确保流畅切换

### 技术实现

- **图片来源**：
  - Unsplash API（提供高质量免费图片）
  - Picsum Photos（随机图片服务）
  - 相关主题关键词：space marine, warhammer, sci-fi warrior, futuristic armor 等

- **随机算法**：使用 Fisher-Yates 洗牌算法确保真正的随机性

- **浏览逻辑**：
  - 启动时预加载前5张图片
  - 手动切换时按需加载图片
  - 自动预加载当前图片的前后相邻图片
  - 使用CSS过渡效果实现平滑切换
  - 100张图片浏览完后重新洗牌

- **可靠性保障**：
  - 图片加载失败自动重试（最多3次，每次间隔1秒）
  - 10秒加载超时保护
  - 失败后自动使用占位符图片
  - 实时显示每张图片的加载状态

- **性能优化**：
  - 图片尺寸优化为800x600，减少加载时间
  - 预加载的图片自动缓存在内存，切换瞬间完成
  - 智能预加载策略：只预加载相邻图片，节省带宽
  - 浏览器级别的图片缓存支持

```javascript

    // ...
}, 10000); // 10000 = 10秒，可以调整
```

```javascript
for (let i = 0; i < 100; i++) { // 修改100为其他数字
```

### 使用自己的图片

如果你想使用自己的战锤40K图片，可以直接替换 `imageUrls` 数组：

```javascript
const imageUrls = [
    'your-image-url-1.jpg',
    'your-image-url-2.jpg',
    // ... 更多图片URL

```

- 采用手动浏览模式，可以确保每张图片完全加载后再查看
